# 建築 AI 知識基礎設施

> **一句話到一棟樓** — From One Sentence to a Building
>
> 為 AI 時代設計的建築產業知識基礎設施。不只是知識整理，而是讓人類能瀏覽學習、讓 AI 能直接讀取並執行的雙語雙層知識庫。

---

## 這個知識庫涵蓋什麼？

整個知識庫分為 **9 大核心分類**：

| # | 核心分類 | 涵蓋範圍 |
|---|----------|----------|
| 1 | **建築設計與規劃** | 概念設計、空間規劃、建築類型學 |
| 2 | **專業複委託** | 材料選材、結構系統、機電系統 |
| 3 | **建築性能** | 光環境、音環境、永續建築、計算工具 |
| 4 | **建築法規** | 消防安全、無障礙設計、容積率計算、施工文件 |
| 5 | **專案管理** | 時程、預算、風險、品質、契約管理 |
| 6 | **經營管理** | 酬金計算、事務所營運、證照進修 |
| 7 | **建築施工與材料** | 施工方法、材料選擇、品質管制 |
| 8 | **建築執照** | 建造執照、雜項執照、使用執照、拆除執照 |
| 9 | **公共工程** | 公開招標、公開閱覽流程 |

---

## 為什麼這個知識庫很特別？

**雙語雙層結構**是這個專案最大的特色。每個知識模組採用「上層中文（人類入口）+ 下層英文（AI 技能）」的架構：

```
公開招標/                    ← 人類直覺中文分類
├── domain.md                ← 人類打開第一眼看到的中文說明
└── public-bidding/          ← AI 自動識別的英文技能資料夾
    ├── SKILL.md             ← AI 執行指令
    ├── references/          ← 參考法規
    └── scripts/             ← 執行腳本
```

這意味著什麼？意味著你不但可以自己瀏覽學習，還能讓 AI（比如 Claude）直接讀取並執行這些知識。這不是普通的知識整理，而是真正為 AI 時代設計的知識基礎設施。

## 相關開源工具

我們很常「幫客戶做工具」，但我們真正想做的是——**讓產業共好**。以下是我們開源的建築 AI 工具：

### 🗺️ OSM_downloader_html — 從地圖下載 3D 建築模型

做建築設計時，你經常需要基地周邊的建築資料。這是一個**純網頁端**的輕量化工具：

- 在 OpenStreetMap 地圖上畫一個框，選取你想要的區域
- 自動下載該區域內所有建築物的 3D 模型（OBJ 格式）
- 建築物依照類型自動上色（住宅淺藍、商業淺紅、辦公粉紅⋯⋯）
- 支援 Rhino 匯入，座標系統以選取中心為原點，不會破面

技術：**Three.js + Leaflet + Overpass API**，全部在瀏覽器端運算，不需後端伺服器。打開網頁、畫框、下載，三步完成。

### 📝 Trilium_MCP — 讓 AI 直接操作你的筆記

如果你用 Trilium Notes 做知識管理，這個 MCP Server 讓 AI（Claude、Gemini 等）可以直接跟你的筆記庫互動：

- 搜尋、讀取筆記內容
- 建立、修改、刪除筆記
- 移動筆記、整理結構
- 管理標籤和屬性

設定方式很簡單：安裝後在你的 MCP Client 設定檔裡加一行即可。

> ⚠️ **注意**：因為有寫入權限，使用前請務必備份筆記庫。

### 📐 HJPLUS_Taiwan_building_code_tracker_MCP — 建築法規即時查詢

整合兩個最重要的資料來源：

- **全國法規資料庫** — 建築技術規則條文
- **內政部國土管理署** — 解釋函令

技術：採用 **Playwright Headless Browser**，因為政府網站有 WAF 防護和動態渲染，用瀏覽器自動化技術繞過限制，確保抓到最新資料。

你可以直接對 AI 說：「搜尋建築技術規則中關於『活載重』的規定。」「幫我查一下『採光』相關的解釋令。」

### 📥 HJPLUS_PCC_downloader_MCP — 公共工程施工規範下載

承接公共工程時，施工綱要規範是必備文件。這個工具從「公共工程雲端服務網」自動化搜尋並下載：

- 瀏覽所有章節清單（動態讀取，不硬編碼）
- 關鍵字或 5 位碼規範編號搜尋
- 批次下載，支援 DOC / ODT / XLS / ODS / PDF 多種格式
- 檔案自動儲存到系統下載資料夾

同樣使用 **Playwright** 驅動，因為目標網站是動態網頁。

### 🔍 SearchProcurementTenders-crawler.Ver — 標案查詢爬蟲版

直接介接政府電子採購網，自動抓取最新標案情報：

- 直接抓取官網資料，無 API 延遲
- 自動處理 Big5 / UTF-8 編碼，不會亂碼
- 自動計算「等標期」與「剩餘天數」
- 輸出美化的 Markdown 表格，AI 可以直接理解

你可以對 AI 說：「幫我找關於『室內裝修』的標案。」「最近有哪些『新建工程』的標案快截止了？」
