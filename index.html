§ The Architecture · 雙語雙層

為什麼這個知識庫很特別？

雙語雙層結構是這個專案最大的特色。每個知識模組採用「上層中文（人類入口）+ 下層英文（AI 技能）」的架構：

公開招標/                    ← 人類直覺中文分類
├── domain.md                ← 人類打開第一眼看到的中文說明
└── public-bidding/          ← AI 自動識別的英文技能資料夾
    ├── SKILL.md             ← AI 執行指令
    ├── references/          ← 參考法規
    └── scripts/             ← 執行腳本

這意味著什麼？意味著你不但可以自己瀏覽學習，還能讓 AI（比如 Claude）直接讀取並執行這些知識。這不是普通的知識整理，而是真正為 AI 時代設計的知識基礎設施。

§ Open Tools · 相關開源工具

相關開源工具

我們很常「幫客戶做工具」，但真正想做的是——讓產業共好。

🗺️ OSM_downloader_html — 從地圖下載 3D 建築模型

純網頁端的輕量化工具，幫你取得基地周邊建築資料。

  • 在 OpenStreetMap 地圖上畫框選取區域
  • 自動下載區域內所有建築 3D 模型（OBJ 格式）
  • 依建築類型自動上色（住宅淺藍、商業淺紅、辦公粉紅⋯⋯）
  • 支援 Rhino 匯入，以選取中心為原點，不破面

技術：Three.js + Leaflet + Overpass API，全瀏覽器端運算，無需後端。

📝 Trilium_MCP — 讓 AI 直接操作你的筆記

讓 AI（Claude、Gemini 等）直接跟你的 Trilium 筆記庫互動。

  • 搜尋、讀取筆記內容
  • 建立、修改、刪除筆記
  • 移動筆記、整理結構、管理標籤與屬性
⚠️ 因為有寫入權限，使用前請務必備份筆記庫。

📐 HJPLUS_Taiwan_building_code_tracker_MCP — 建築法規即時查詢

整合全國法規資料庫（建築技術規則條文）與內政部國土管理署（解釋函令）。

  • 採用 Playwright Headless Browser，繞過政府網站 WAF 與動態渲染
  • 確保抓到最新資料
「搜尋建築技術規則中關於『活載重』的規定。」「幫我查一下『採光』相關的解釋令。」

📥 HJPLUS_PCC_downloader_MCP — 公共工程施工規範下載

從「公共工程雲端服務網」自動化搜尋並下載施工綱要規範。

  • 瀏覽所有章節清單（動態讀取，不硬編碼）
  • 關鍵字或 5 位碼規範編號搜尋
  • 批次下載 DOC / ODT / XLS / ODS / PDF

🔍 SearchProcurementTenders-crawler.Ver — 標案查詢爬蟲版

直接介接政府電子採購網，自動抓取最新標案情報。

  • 直接抓官網資料，無 API 延遲
  • 自動處理 Big5 / UTF-8 編碼，不亂碼
  • 自動計算「等標期」與「剩餘天數」，輸出 Markdown 表格
「幫我找關於『室內裝修』的標案。」「最近有哪些『新建工程』的標案快截止了？」
