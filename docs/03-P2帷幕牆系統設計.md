# P2 細部設計：帷幕牆系統（CW-01 / GL-01）

> 範疇：在 P1 鰭片立面之上，把「帷幕基準面」升級為真正的 **豎框 + 橫框 + 玻璃單元**。
> 對應：`docs/01`（路線圖 P2）、`docs/02`（P1 基礎、座標系）。

---

## 1. 範疇

- **做**：垂直豎框（mullion）、水平橫框（transom，逐層）、玻璃單元（逐格半透明面）。
- **暫不做**：開窗扇、五金、單元式接縫細部、雙層 Low-E 玻璃厚度建模（以單面 + 透明度表現）。

## 2. 座標與分側（沿用 P1）

| 元素 | Y 方向 |
|---|---|
| 鰭片 (W-02) | 自 Y=0 向室外 **+Y** 出挑 `fin_depth` |
| 帷幕框料 (CW-01) | 自 Y=0 向室內 **-Y** 出 `mullion_depth` |
| 玻璃 (GL-01) | 置於框料中線 `Y = -mullion_depth/2` |

兩者分屬帷幕面兩側，符合「外遮陽 + 內帷幕」的剖面邏輯。

## 3. 新增參數（Schema）

| 鍵 | 中文 | 類 | 預設 | 範圍 |
|---|---|---|---|---|
| `panel_width` | 玻璃單元寬 | length | 36 | 12–120 |
| `mullion_width` | 框料寬 | length | 2 | 0.5–12 |
| `mullion_depth` | 框料深 | length | 5 | 1–24 |
| `glass_color` | 玻璃顏色 | hex | `#bcd8e6` | — |
| `glass_opacity` | 玻璃透明度 | ratio | 0.35 | 0.05–1.0 |

**驗證**：`mullion_width < panel_width`（否則無玻璃可容）。

## 4. 格網演算法（與鰭片同精神）

```
cols      = max(round(W / panel_width), 1)   # 開間數
actual_pw = W / cols                          # 均分修正
x_lines   = [0, pw, 2pw, ..., W]              # 豎框線 (cols+1 條)
z_lines   = [0, fh, 2fh, ..., total_h]        # 橫框線 (floor_count+1 條)
```
玻璃格子：每 (col × floor) 一片，四邊內縮 `mullion_width/2` 避免與框料重疊。

驗算：W=144、單元寬 36 → cols=4、實際 36"、5 條豎框（測試 `test_panel_grid`）。

## 5. 構件樹（接在 P1 之後）

```
[AutoFacade]
 ├─ [Floors] ...
 ├─ [Fins] ...
 └─ [CurtainWall]
     ├─ [Mullions]  (共用 AF_MullionV instance × (cols+1))
     ├─ [Transoms]  (共用 AF_Transom  instance × (floor_count+1))
     └─ [Glass]     (半透明面 × cols × floor_count)
```

共用定義 `AF_MullionV` / `AF_Transom`，玻璃因尺寸隨格變動而直接建面。
