## 1. P1 範疇精確定義

### 1.1 P1 要產生的幾何
單一立面，含以下三類構件（最小可驗證集合）：

1. **垂直遮陽鰭片 (W-02)**：沿立面寬度方向的矩形柱陣列。
2. **樓板 (RB-01)**：每層一片水平板，鰭片掛在板緣。
3. **背板/立面基準面**：一個代表帷幕牆位置的薄面（P2 才換成真正的玻璃帷幕），作為鰭片的定位參考與視覺背景。

### 1.2 P1 明確「不做」
- 不做玻璃單元分割、框料、結構樑、陽台欄杆（P2/P6）。
- 不做防水落水細部。
- 不做多立面、轉角。
- 不做 BOM CSV 匯出（僅在面板顯示「鰭片支數」即可）。

### 1.3 P1 驗收標準（Definition of Done）
- 輸入新版參數（寬144"、3開間、13支、間距12"、寬2.5"、深10"、深鐵灰）→ 一鍵生成截圖等級的鰭片立面。
- 改任一參數再按一次 → 就地重建（不殘留舊幾何、單步 Undo 可還原）。
- 單位切換 inch ↔ cm，數值與模型一致。
- 輸入會造成「太密/溢出」的參數時，面板擋下並提示。

## 2. 座標系統與基準

統一約定（右手座標，SketchUp 預設）：

| 軸 | 意義 | 方向 |
|---|---|---|
| **X** | 立面寬度方向（鰭片沿此陣列） | 向右為正 |
| **Y** | 立面深度方向（鰭片出挑、樓板進深） | 向外為正 |
| **Z** | 高度方向（樓層往上） | 向上為正 |

- **原點 (0,0,0)**：立面左下角、帷幕牆基準面上。
- 帷幕牆基準面位於 **Y = 0**；鰭片從 Y=0 向外（+Y）出挑 `fin_depth`。
- 第一層樓板頂 Z=0；往上每層 +`floor_height`。

## 3. 參數 Schema（P1 子集 + 單位機制）

### 3.1 P1 參數表

| 鍵 | 中文 | 型別 | 單位類 | 預設 | 範圍 | 必填 |
|---|---|---|---|---|---|---|
| `elevation_width` | 立面寬度 | float | length | 144 | 24–600 | ✓ |
| `bay_count` | 開間數 | int | count | 3 | 1–10 | ✓ |
| `floor_height` | 樓層高 | float | length | 144 | 96–240 | ✓ |
| `floor_count` | 樓層數 | int | count | 3 | 1–10 | ✓ |
| `fin_layout` | 鰭片佈局模式 | enum | — | `by_count` | by_count / by_spacing | ✓ |
| `fin_count` | 鰭片數量 | int | count | 13 | 2–200 | 條件 |
| `fin_spacing` | 鰭片間距 | float | length | 12 | 2–120 | 條件 |
| `fin_width` | 鰭片寬度(面外厚) | float | length | 2.5 | 0.25–24 | ✓ |
| `fin_depth` | 鰭片深度(出挑) | float | length | 10 | 1–48 | ✓ |
| `fin_color` | 鰭片顏色 | hex | — | `#3a3f44` | — | ✓ |
| `slab_thickness` | 樓板厚 | float | length | 8 | 4–36 | ✓ |
| `slab_overhang` | 樓板出挑 | float | length | 24 | 0–60 | ✓ |
| `units` | 顯示單位 | enum | — | `inch` | inch / cm | ✓ |

> `fin_layout` 決定 `fin_count` 與 `fin_spacing` 誰是輸入、誰被推算（見 §5）。

### 3.2 單位切換機制（核心約定）

**鐵則：內部一律以英吋運算與儲存；單位只影響「顯示與輸入」。**

```
顯示/輸入 (inch 或 cm)  ──轉入──►  內部模型 (一律 inch)  ──建模──►  SketchUp (inch)
                       ◄──轉出──
```

- 轉換常數：`1 inch = 2.54 cm`。
- 流程：
  1. UI 以使用者選的單位顯示數值。
  2. 送入 Ruby 前，UI 標明 `units`；Ruby 一律先轉成 inch 再驗證/建模。
  3. JSON 方案檔以 inch 儲存 + 記錄 `display_units`，跨單位開啟不失真。
- `count` 類（開間數、鰭片數、樓層數）與 `length` 類分開處理，count 不轉換。
- SketchUp API 取長度可用 `value.inch` 或 `length.to_l`，避免硬編數字。

## 4. 構件樹（Group / Component 結構）

```
[AutoFacade]                         ← 頂層 Group（重建只動這個；標記屬性 generated=true）
 ├─ [Floors]                         ← Group
 │   ├─ Slab#1  (ComponentInstance)  ← 共用定義 SlabDef
 │   ├─ Slab#2  (ComponentInstance)
 │   └─ Slab#3  (ComponentInstance)
 ├─ [Fins]                           ← Group
 │   ├─ Fin#1 .. Fin#13 (ComponentInstance) ← 全部共用定義 FinDef
 ├─ [CurtainBase]                    ← Group：帷幕牆基準薄面（P2 取代）
 └─ 屬性: generated=true, scheme="新版(修正)", schema_version=1
```

設計要點：
- **共用定義**：`FinDef` 只建一次（一根 `fin_width × fin_depth × floor_total_height` 的柱）；13 支皆為 instance，改定義即全改、面數最低。
- **可識別**：頂層群組寫入 attribute（`dict="AutoFacade"`），重建時用它找回並清空，**絕不誤刪使用者其他物件**。
- **Undo 友善**：整個生成包在一次 `start_operation/commit_operation`。

## 5. 鰭片佈局演算法（杜絕「太密/溢出」的關鍵）

立面寬度固定為 `W = elevation_width`。鰭片視為**等距分佈在 0..W 之間**。

### 5.1 兩種模式

**模式 A：`by_count`（鎖定數量，推算間距）**
```
n = fin_count                       # 例 13
if n < 2: error("鰭片數量至少 2 支")
spacing = W / (n - 1)               # 端點各一支，13 支 → 12 段
fin_spacing := spacing              # 回填顯示
# 第 i 支中心 X：
x_i = i * spacing,  i = 0 .. n-1
```
新版：W=144、n=13 → spacing = 144/12 = **12"**（與你表格一致 ✓）。

**模式 B：`by_spacing`（鎖定間距，推算數量）**
```
s = fin_spacing                     # 例 12
if s <= fin_width: error("間距需大於鰭片寬度")
segments = round(W / s)             # 取整段數
n = segments + 1
actual_spacing = W / segments       # 均分修正，使端點貼齊
fin_count := n; fin_spacing := actual_spacing(顯示提示「實際間距」)
x_i = i * actual_spacing
```

> 設計理由：兩模式互斥，避免「數量×間距 ≠ 立面寬度」的根本矛盾。
> 這正是舊版問題——間距 8" × 12 支硬塞進 96" 立面 → 看起來「太密」。

### 5.2 驗證規則（建模前必跑）

| 編號 | 規則 | 觸發訊息 |
|---|---|---|
| V1 | `fin_width < fin_spacing` | 「鰭片寬度需小於間距，否則重疊」 |
| V2 | `by_count` 時 `fin_count >= 2` | 「鰭片數量至少 2 支」 |
| V3 | 淨間隙 `spacing - fin_width > 0.5"` | 「鰭片過密（淨間隙不足），建議減少數量或加寬間距」 |
| V4 | 所有 length 參數 > 0 且在範圍內 | 「{欄位} 超出允許範圍 {min}–{max}」 |
| V5 | `fin_depth >= fin_width` 建議（非強制） | 警告：鰭片偏厚，遮陽效果有限 |

V3 就是把「太密」量化擋下的規則。

## 6. 建模引擎流程（虛擬碼）

```ruby
def generate(raw_params)
  p = Parameters.normalize(raw_params)   # 單位轉 inch + 填預設
  errs = Parameters.validate(p)          # §5.2
  return {ok: false, errors: errs} unless errs.empty?

  layout = FinLayout.compute(p)          # §5.1 → {count, spacing, xs:[...]}
  model = Sketchup.active_model
  model.start_operation("Generate Auto Facade", true)

  root = find_or_create_root(model)      # [AutoFacade]，清空舊內容
  fin_def  = build_fin_definition(model, p)    # FinDef（柱）
  slab_def = build_slab_definition(model, p)   # SlabDef（板）

  total_h = p[:floor_height] * p[:floor_count]

  floors = root.entities.add_group; name(floors,"Floors")
  (0...p[:floor_count]).each do |f|
    z = f * p[:floor_height]
    tr = Geom::Transformation.new([ -p[:slab_overhang], -p[:slab_overhang], z ])
    floors.entities.add_instance(slab_def, tr)
  end

  fins = root.entities.add_group; name(fins,"Fins")
  layout[:xs].each do |x|
    tr = Geom::Transformation.new([ x - p[:fin_width]/2.0, 0, 0 ])
    fins.entities.add_instance(fin_def, tr)
  end

  build_curtain_base(root, p, total_h)   # Y=0 薄面（P2 取代）
  Materials.apply_fin_color(fin_def, p[:fin_color])
  tag_root(root, p, layout)              # 寫入 attribute

  model.commit_operation
  { ok: true, fin_count: layout[:count], fin_spacing_in: layout[:spacing] }
rescue => e
  model.abort_operation
  { ok: false, errors: ["建模失敗：#{e.message}"] }
end
```

### 6.1 單一鰭片定義
```ruby
def build_fin_definition(model, p)
  d = model.definitions.add("FinDef")
  ent = d.entities
  w, dep, h = p[:fin_width], p[:fin_depth], p[:floor_height]*p[:floor_count]
  # 底面在 XY 平面，矩形 w(X) × dep(Y)
  face = ent.add_face([0,0,0],[w,0,0],[w,dep,0],[0,dep,0])
  face.reverse! if face.normal.z < 0
  face.pushpull(h)                        # 沿 +Z 擠出整高
  d
end
```

### 6.2 樓板定義
```ruby
def build_slab_definition(model, p)
  d = model.definitions.add("SlabDef")
  ent = d.entities
  w   = p[:elevation_width] + 2*p[:slab_overhang]
  dep = p[:fin_depth] + p[:slab_overhang]     # 概略進深（P1）
  face = ent.add_face([0,0,0],[w,0,0],[w,dep,0],[0,dep,0])
  face.reverse! if face.normal.z < 0
  face.pushpull(-p[:slab_thickness])          # 板厚往下
  d
end
```

> 注意：定義內幾何以「定義局部原點」為基準，靠 `add_instance` 的 transformation 定位，
> 不在定義裡硬寫世界座標，才能讓共用定義成立。

## 7. 材質
```ruby
def apply_fin_color(fin_def, hex)
  m = Sketchup.active_model
  mat = m.materials["FinColor"] || m.materials.add("FinColor")
  mat.color = hex_to_color(hex)               # 例 #3a3f44 深鐵灰
  fin_def.entities.grep(Sketchup::Face).each { |f| f.material = mat }
end
```
- P1 鰭片：實色（深鐵灰 `#3a3f44`）。
- 帷幕基準面：淡藍半透明（`alpha ≈ 0.35`）暫代玻璃。

## 9. 錯誤處理策略

| 情境 | 處理 |
|---|---|
| 參數驗證失敗 | 不進入建模；回傳 `errors[]`，UI 標紅對應欄位 |
| 建模中例外 | `model.abort_operation`（回滾），回傳友善訊息 |
| 找不到既有 root | 視為首次生成，直接新建 |
| 單位/型別解析失敗 | 視為驗證錯誤，提示「數值格式不正確」 |
