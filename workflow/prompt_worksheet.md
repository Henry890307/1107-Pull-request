# Prompt 工作表 — 6 段 × 20 秒（24 個 5 秒片段）

每跑一次 `wan22_1080p60_i2v.json` 就生一個 5 秒片段。每次只改兩樣：
1. **LoadImage 的 start_frame.png** = 上一個片段的「最後一格」（第 1 個片段可放自備起始圖，或改用純文生）。
2. **正向 CLIPTextEncode 的 prompt** = 下表對應格子。

> 接續訣竅：相鄰片段的 prompt 要**共用場景元素**（同一主角、同一環境、光線連續），畫面才接得順。每段最後一格會自動成為下一段的起點。

---

## 共用負向 prompt（貼到負向 CLIPTextEncode）
```
色彩暗淡, 模糊, 變形, 多餘手指, 殘肢, 低畫質, 雜訊, 浮水印, 字幕, 過曝, 閃爍, 畫面撕裂
```

## 最後合併（24 個 mp4 → 一支 2 分鐘）
把 24 個輸出的 mp4 路徑寫進 `list.txt`（每行 `file 'D:/clips/clipXX.mp4'`），然後：
```powershell
ffmpeg -f concat -safe 0 -i list.txt -c copy final_1920x1080_60fps.mp4
```
